# Image Requests — ready-to-paste prompts for ChatGPT

Companion to `CHATGPT_IMAGE_BRIEF.md`. Paste **Step 0** once to lock the style,
then send each numbered prompt one at a time in the same conversation and save
each file with the name shown. Hand the finished PNGs back for import.

---

## Step 0 — paste first (locks the style)

> You are generating illustrations for a hand-drawn whiteboard video series.
> Every image must follow these rules exactly, no exceptions:
> - Flat vector-style marker illustration. Confident uniform charcoal outline,
>   minimal flat shading. No gradients, no photorealism, no 3-D.
> - Palette only: charcoal `#262B2E`, teal `#1F6F70`, burnt orange `#CA5330`,
>   amber glow `#E8A33D`, cream `#F9F7F0` (highlights only).
> - Fully transparent background — real PNG alpha. Never draw a checkerboard to
>   represent transparency; see-through areas must be actual transparency.
> - No text, letters, numbers, logos, or borders. One subject, centred, ~8%
>   margin.
> - Output a transparent PNG, ~1024px.
> Confirm you understand, then wait for each image request.

same subject, position and scale; only the state changes. **The base stays
fixed in every frame.** No per-frame borders, no checkerboard, transparent
background.
