# How-to-Sing Reference Library

One guide per song, written for a real singer preparing a real performance —
usually a live/karaoke setting. The song pool is the repo's karaoke catalogue
(`../songbook_lite.csv`); the technique knowledge behind every guide lives in
the linked `aaroncodex` repository (see `../SINGING_LIBRARY_LINK.md`).

## Layout

```
guides/
├── README.md            # you are here
├── TEMPLATE.md          # copy this to start a new guide
└── <artist>/<song>.md   # one folder per artist, one file per song
```

File and folder names are lowercase, hyphenated slugs of the artist and song
title, e.g. `guides/chris-stapleton/tennessee-whiskey.md`.

## What a guide is (and isn't)

A guide describes **what the song demands of a voice**: key and range,
tessitura, where the hard notes sit, the breath map, register events, style and
groove, and a practical plan for learning it. Use the template's sections.

A guide is **not** a performance review. Take-by-take analysis, scores and
coaching off a specific recording belong to the `aaroncodex` engine and its
rules — never put a `/10` score in a guide (see the shared link file for why).

## Prior art
